# 📅 BKLY SaaS

A full-stack appointment booking platform that enables customers to book appointments with businesses while providing powerful management tools for business owners, staff, and administrators.

## 🛠️ Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- React Hook Form
- Zod
- Axios

### Backend

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- Passport.js
- JSON Web Tokens (JWT)
- Nodemailer

### Tools

- Git & GitHub
- Thunder Client
- Prettier

## ✨ Features

### Customer

- Register and authenticate
- Browse businesses
- Book appointments
- View booking history
- Make payments
- Leave reviews

### Business Owners

- Manage services
- Manage staff
- Configure availability
- Manage bookings
- View ratings and reviews

### Admin

- Manage users
- Manage businesses
- Moderate reviews
- Monitor platform activity
